# NovaSpace — Web Technologies Assignment 01

A professional five-page responsive website built with HTML5 and Tailwind CSS.

## Pages

- Home: `index.html`
- About: `src/pages/about.html`
- Contact: `src/pages/contact.html`
- Sign In: `src/pages/signin.html`
- Sign Up: `src/pages/signup.html`

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server.

## Contact form

The Contact page uses Netlify Forms markup (`data-netlify="true"`). Deploy the project to Netlify and enable form handling for real submissions.
